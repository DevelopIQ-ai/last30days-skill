Add `last30days settings`: a local settings page for sources and credentials. It lists every source with its live status, what it contributes, its backend chain, and an inline field for the credential that unlocks it, plus a tab covering every API key with what it unlocks and where to get one. Switches write `INCLUDE_SOURCES` / `EXCLUDE_SOURCES`; keys are persisted to `~/.config/last30days/.env` at `0600` through the same allowlisted path as `setup --store-key`. Source status is read from the existing `doctor` report, so the page and `doctor` cannot disagree.

The server binds loopback only on an ephemeral port, authenticates every request with a per-process session token, refuses non-loopback `Host` and cross-site `Origin`, and never sends a stored credential's value to the browser. Supports `--port` and `--no-open`; no new dependencies.

Source and credential rows carry brand marks, vendored from Simple Icons (CC0-1.0) as inline SVG so the page needs no network access and no npm dependency. Near-black marks lighten for the dark theme. Amazon, LinkedIn, and OpenAI were withdrawn from Simple Icons at the rightsholders' request and get a neutral monogram rather than a mark sourced elsewhere; non-brand sources (web, jobs, library) get a generic glyph.
